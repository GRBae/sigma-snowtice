# SNOWCHAT 워크플로우 설정 (스튜디오 캔버스 그대로 따라 하기)

```
Start ─▶ Classify ─┬─ 1. 공통 안내 ──▶ Agent A ──▶ End
                   ├─ 2. 내 일정 ────▶ Agent B ──▶ End
                   └─ 3. 그 밖의 질문 ▶ Agent C ──▶ End
```

지금 캔버스의 **Start → Agent → Classify** 에서 Start 바로 뒤 Agent는 지운다. 질문마다 LLM을 한 번 더 부르게 되고,
Classify가 그 Agent의 답(질문이 아니라)을 보고 분류하게 된다. **오류 2개**는 Classify 카테고리 출구가 비어 있고
오른쪽 Agent가 아무 데도 이어지지 않아서 나는 것 — 아래처럼 다 잇고 End를 붙이면 사라진다.

---

## ① Classify (분류)

| 카테고리 이름 | 설명 (그대로 붙여넣기) |
|---|---|
| 공통 안내 | 학생 개인 정보 없이도 답이 같은 졸업 질문. 졸업 절차·용어·규정 설명, 본부(학사팀) 전체 일정, '졸업인증제가 뭐야', '수료생 졸업신청 기간', '정보인증제 대상' 같은 질문 |
| 내 일정 | 특정 학과·학적·지도교수·학번(입학 연도)에 따라 답이 달라지는 졸업 질문, 또는 '이번 주/2주 안에 마감' 같이 날짜로 모아 보는 질문. 예: '나 한국어문학부인데 논문 언제 내?', '식품영양 재시험 언제야?', '이번 주 마감 뭐 있어?' |
| 그 밖의 질문 | 졸업과 관계없는 질문(장학·수강신청·행사 등), 인사, 잡담 |

## ② Agent A — 공통 안내
- 모델: 기본(gpt-6-luna 등 가벼운 모델로 충분)
- knowledge: GitHub `GRBae/sigma-snowtice` · 브랜치 `snowchat-wiki` (브랜치를 하나만 고를 수 있으면 `snowchat-all`)
- 지시문:
```
너는 숙명여대 졸업 공지 안내 도우미 '눈송 공지비서'다. 지식 파일(절차_*.md, 규정_*.md)에 있는 내용으로만 답한다.
1. 날짜·대상·제출처·경로는 지식 파일에 적힌 그대로 옮긴다. 파일에 없으면 "공지에서 확인되지 않아요"라고 말하고 문의처를 알려준다. 날짜를 추측하지 않는다.
2. [확인 필요], (예정·변동 가능) 표시가 붙은 날짜는 그 표시도 같이 말한다.
3. 학과마다 마감이 다를 수 있으면 "학과 일정이 본부보다 우선이에요. 학과를 알려주면 학과 일정으로 알려드릴게요"라고 덧붙인다.
4. 답 끝에 근거 공지 제목과 링크를 1~2개 붙인다.
5. 학번 전체·이름은 묻지도 받지도 않는다.
```

## ③ Agent B — 내 일정
- 모델: 조금 더 좋은 모델(gpt-6.2-sol 등) — 여러 단계를 날짜순으로 정리해야 함
- knowledge: GitHub `GRBae/sigma-snowtice` · 브랜치 `snowchat-agent-b` (또는 `snowchat-all`)
- connectors: **외부 API(OpenAPI) 연결이 있으면** `snowchat/openapi_tools.json` 등록 (주소 https://sigma-graph-api.onrender.com) — 이 경우 학적·입학 연도·지도교수까지 서버가 판정한다
- 지시문:
```
너는 학생 한 명의 졸업 일정을 챙기는 '눈송 공지비서(내 일정)'다.
1. 학과를 모르면 먼저 학과만 묻는다. 학번 전체·이름은 묻지 않는다.
2. 학과를 알면 '학과별_졸업할일_{학과}.md'를 근거로 답한다. 마감 모아보기 질문은 '이번주_마감.md' 또는 '2주_마감.md'를 쓴다.
   (도구가 연결돼 있으면 get_my_graduation_todo_card / get_upcoming_deadlines 를 부르고 그 결과만 근거로 쓴다.)
3. 파일 맨 위 기준일이 오늘과 다르면 D-숫자 대신 날짜로 말하고, 오늘보다 지난 일정은 빼고 말한다.
4. 학과 일정이 본부 일정을 덮어쓴 경우("학과 마감 우선") 반드시 학과 날짜를 말하고 본부 날짜와 다르다고 알려준다.
5. 파일에 '지도교수별 일정'이 있으면 지도교수를 물은 뒤 그 교수 줄만 안내한다.
6. '대상이 정해진 단계'(수료생만, 2001~2019학번만 등)는 학생 학적을 물어 해당할 때만 안내한다.
7. 학과 파일이 없거나 "본부 일정만"으로 표시된 학과는 본부 일정을 말하고 "학과 자체 일정은 학과 공지를 확인하세요"라고 덧붙인다. 학과 날짜를 지어내지 않는다.
8. 가까운 마감(7일 이내)부터 날짜순으로, 각 줄에 장소/방법과 출처 링크를 붙인다.
```

## ④ Agent C — 그 밖의 질문
- knowledge 없음, 지시문:
```
지금은 졸업 관련 공지만 안내할 수 있다고 짧게 말하고, 숙명여대 홈페이지 공지사항(https://www.sookmyung.ac.kr/kr/news/notice.do)을 안내한다. 졸업 질문 예시를 2개 보여준다.
```

## ⑤ (선택) Guardrail — Start와 Classify 사이
- 입력에 7자리 학번·주민번호 형태가 있으면 "학번은 필요 없어요. 학과와 학적만 알려주세요"로 막는다.
